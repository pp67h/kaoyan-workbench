🫐 安装与更新说明

本工作台是一个「单文件网页应用」，所有功能都在这一个 HTML 里。

📱 装到手机 / 平板

1
OPPO Reno 13：用自带浏览器或 Chrome 打开本页面链接 → 点右上角 ⋮ → 「安装应用」/「添加到主屏幕」。桌面会出现 App 图标，点开即全屏运行。
2
华为 MatePad 11.5s：用华为浏览器或 Chrome 打开链接 → 点菜单 → 「添加到主屏幕」。首次打开建议联网，以便加载最新版。
🔄 自动更新（重点）：以后你让我加功能、修 bug，我改完重发同一个链接，你重开 App 就是新版，不用重新下载、不用重装。若没立刻生效，彻底关闭再打开一次即可。

🔗 两台设备互通

☁️ 两台设备实时云同步：手机和平板都装好后，分别打开 App → 右栏「☁️ 云同步」→ 输入同一个同步码（如 kao2026）→ 点「开启同步」。之后两边自动互通：哪边数据多就传哪边、重复内容不重复传、删掉的任务也会同步删掉。数据会先存在本地，再同步到云端。
⚠️ 数据安全第一：重要节点仍建议用「⚙️ 数据管理 → 导出备份」保存一份 JSON 到自己手机/云盘，作为额外保险。

❓ 常见问题

打开白屏 / 转圈？
本应用需要联网加载最新版。检查网络后重开；若完全断网，本地数据（任务、打卡、生词）仍在，只是暂时不能云端同步。
找不到「添加到主屏幕」？
OPPO/华为 一般在浏览器右上角 ⋮ 菜单里；也可在浏览器「分享」里找「添加到主屏幕」。
以后有更新怎么办？
不用你操作——我改完重发同链接，你重开 App 自动变新版。
